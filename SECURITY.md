# Security and privacy

This is an experimental BLE/CGM research project, not a medical device. Never rely on it for treatment decisions.

Please do not publish raw logs, personal sensor identifiers, glucose readings, pairing codes, saved authentication keys, signing keys, or access tokens in issues or pull requests. Review diagnostics locally and share only the minimum sanitized excerpt needed to explain a failure.

Do not report vulnerabilities by posting secrets or live sensor credentials publicly. Until a private reporting channel is configured, describe the issue without including the secret material.
